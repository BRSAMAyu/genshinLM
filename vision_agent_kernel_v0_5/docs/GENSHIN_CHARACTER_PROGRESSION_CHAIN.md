## 阶段一：升级到 40 级

### 目标

将雷电将军从 Lv.1 提升到 Lv.40，完成第一次突破。

### 材料需求

| 材料 | 数量 | 来源 |
|------|------|------|
| 大英雄的经验 (紫色经验书) | ~70-80 本 | 地脉衍出 (蓝色花朵, 20 树脂/次) |
| 摩拉 | ~200,000 | 地脉衍出 (金色花朵, 20 树脂/次) |
| 最胜紫晶碎屑 | x1 | 雷音权现 / 无相之雷 |
| 旧刀镡 | x3 | 海乱鬼 / 野伏众 (稻妻各岛) |
| 天云草实 | x3 | 清籁岛采集 |
| 摩拉 (突破) | 20,000 | 同上 |

### 操作步骤

1. 完成稻妻主线，解锁清籁岛和雷音权现
2. 用风之翼 / 传送点跑图采集 3 个天云草实 (清籁岛遍布，常成对出现)
3. 击杀 3 个野伏众获取旧刀镡
4. 打一次雷音权现 (30 树脂) 获取最胜紫晶碎屑 + 雷光棱镜
5. 刷地脉花获取经验书和摩拉
6. 在角色界面升级到 20 级，然后进行第一次突破到 40 级

### 树脂消耗

| 项目 | 树脂 |
|------|------|
| 经验书 (地脉花 x10) | 200 |
| 摩拉 (地脉花 x5) | 100 |
| 雷音权现 (1 次) | 30 |
| **小计** | **~330** |

### 耗时估算

约 1-2 天自然树脂恢复 (每日 180 树脂)。

**武器属性 (R5):**

- 基础攻击力: 510 (90 级)
- 副属性: 元素充能效率 45.9%
- 被动: 元素爆发暴击率 +12%，元素爆发伤害 +32%

## 阶段四：圣遗物装备

### 推荐套装

**绝缘之旗印 4 件套 (Emblem of Severed Fate)**

- 2 件套效果: 元素充能效率 +20%
- 4 件套效果: 元素爆发造成的伤害提高，相当于元素充能效率的 25%，最高通过这种方式提升 75%

这是雷电将军的 **唯一毕业套装**，没有替代方案。4 件套效果直接将充能效率转化为爆发伤害，完美契合她的机制。

### 圣遗物副本

- **副本名**: 缘染之庭 (Momiji-Dyed Court)
- **位置**: 稻妻 八酝岛
- **树脂**: 20 / 次
- **掉落**: 50% 概率掉绝缘套，50% 掉追忆套 (Shimenawa's Reminiscence)

### 主词条推荐

| 部位 | 推荐主词条 | 备选 |
|------|-----------|------|
| 生之花 (花) | 生命值 (固定) | -- |
| 死之羽 (羽) | 攻击力 (固定) | -- |
| 时之沙 (沙) | **元素充能效率%** | 攻击力% |
| 空之杯 (杯) | **雷元素伤害加成%** | 攻击力% |
| 理之冠 (冠) | **暴击率% / 暴击伤害%** | 保持 1:2 比例 |

### 副词条优先级

```
元素充能效率% > 暴击率% = 暴击伤害% > 攻击力% > 元素精通
```

### 毕业面板目标

| 属性 | 目标值 | 备注 |
|------|--------|------|
| 元素充能效率 | 250% - 270% | 使用渔获 R5 时; 4 件套上限 300% |
| 暴击率 | 60%+ | 渔获被动额外 +12% |
| 暴击伤害 | 150%+ | 与暴击率保持约 1:2 |
| 攻击力 | 1,400+ | 充能沙 + 渔获基础攻击力较低 |
| 雷元素伤害 | 杯子提供 | 基础即可 |

### 操作步骤

1. 解锁缘染之庭 (Momiji-Dyed Court) 副本
2. 每天用浓缩树脂刷取，每次 20 树脂 (用浓缩则 40 树脂出双份)
3. 优先获取正确的 **沙/杯/冠** 三个主件 (主词条正确即可用)
4. 花/羽 任何 5 星绝缘套都行，副词条好就留着
5. 副词条用「绝缘强化法」: +4 时如果歪到不想要的词条就当狗粮
6. 沙漏 (充能%) 掉率约 10% (20% 类型 x 50% 绝缘)
7. 杯子 (雷伤%) 掉率约 5% (20% 类型 x 50% 绝缘 x 50% 元素杯概率)
8. 头 (暴击率/暴击伤害) 掉率约 10%

### 树脂消耗估算

| 目标 | 估算树脂 |
|------|----------|
| 主词条正确的 5 件套 (不论副词条) | 2,000 - 3,000 |
| 毕业副词条 (20+ 次词条) | 5,000 - 8,000+ |
| 深渊可用 (主词条正确 + 合理副词条) | 2,000 - 4,000 |

### 耗时估算

- 深渊可用水平: 约 2-3 周集中刷取
- 毕业水平: 1-2 个月甚至更长

### 速成建议

- 如果急用，可以用 4 星绝缘套过渡，主词条正确即可
- 花/羽 用任何 5 星散件也可以，核心是沙/杯/冠三件
- **合成台**: 可以用 3 个同一部位的金色圣遗物合成指定部位的绝缘套 (有一定随机性)

## 阶段五：天赋升级

### 天赋升级优先级

**Q (元素爆发: 梦想一刀) > E (元素战技: 神变恶曜眼) > A (普通攻击)**

推荐目标: **Q9 / E9 / A6** (即 9/9/6)

理由:
- 普通攻击对雷电将军的输出贡献极低 (她主要靠 Q 的爆发和重击输出)
- 元素爆发是她的核心输出手段，拉满优先级最高
- 元素战技提供全队能量恢复和协同攻击，其次升级

#### 香菱 -- 副C / 后台火

- **定位**: 元素爆发 (旋火轮) 持续后台火伤 + 触发蒸发
- **武器**: 渔获 (如果雷电将军有专武) / 匣里灭辰 / 喜多院十文字
- **圣遗物**: 绝缘之旗印 4 件套
- **注意**: 如果雷电将军用渔获，香菱需要其他武器
- **获取**: 深境螺旋 3-3 通关赠送 (F2P 稳定获取)

#### 行秋 -- 副C / 后台水

- **定位**: 元素爆发 (虹剑) 提供持续水附着 + 减伤 + 小量治疗
- **武器**: 祭礼剑 (最佳) / 西风剑 / 天目影打刀
- **圣遗物**: 绝缘之旗印 4 件套 或 水2+宗室2
- **获取**: 祈愿获取 (4 星常驻)

#### 班尼特 -- 奶 / 攻击力 Buff

- **定位**: 元素爆发提供巨额攻击力加成 + 治疗
- **武器**: 高基础攻击力武器 (天空之刃 / 暗巷闪光 / 腐殖之剑)
- **圣遗物**: 昔日宗室之仪 4 件套 (全队加攻)
- **注意**: 班尼特的攻击力加成基于他的**基础攻击力** (角色 + 武器)，所以武器基础攻击力越高越好
- **获取**: 祈愿获取 (4 星常驻)

### 输出循环 (Rotation)

  -> 班尼特 Q (元素爆发: 攻击力 buff 区域)

## 总览：树脂消耗与耗时估算

### 全链路树脂消耗汇总

| 阶段 | 主要项目 | 树脂消耗 |
|------|----------|----------|
| 阶段一 | 升级到 40 级 | ~330 |
| 阶段二 | 角色突破 40-90 + 经验书 | ~1,930 |
| 阶段三 | 武器升级 (秘境) | ~400 |
| 阶段四 | 圣遗物 (深渊可用) | ~2,000-4,000 |
| 阶段五 | 天赋秘境 + 周本 | ~1,160 |
| 队友 | 班尼特/香菱/行秋养成 | ~2,000-3,000 |
| **总计** | | **~8,000-11,000** |

### 按自然恢复估算

- 每日自然恢复: 180 树脂
- 每月自然恢复: ~5,400 树脂
- **完整养成周期: 约 1.5-2 个月** (仅算树脂限制)
- 受周本掉落和鱼类刷新限制，实际可能需要 **2-3 个月**

### 加速方法

| 方法 | 效果 |
|------|------|

| 每日委托 | 60 树脂/天 |
| 深境螺旋 | 每月 800 原石 (可用于体力恢复) |
| 异梦溶媒 | 周本材料转换，解决掉落不对的问题 |
