|---------|-----------|-----------|-----------|------|

| **AR 20-35** (中早期) | 天赋秘境 (核心角色) | 武器突破秘境 | 世界Boss (突破材料) | 圣遗物域 |
| **AR 35-45** (中后期) | 天赋秘境 (关键天赋) | 武器突破秘境 | 世界Boss (角色突破) | 圣遗物域 |
| **AR 45-55** (后期) | 圣遗物秘境 (主C首选套装) | 天赋秘境 (辅助角色) | 世界Boss (突破材料) | 地脉花 |
| **AR 55+** (终局) | 圣遗物秘境 (副词条优化) | 周本Boss (折扣后) | 天赋秘境 (皇冠目标) | 地脉花 |

### 2.2 单日树脂预算模板 (200树脂上限)

```
方案A — AR45+ 圣遗物优先:
  浓缩树脂×2 (80树脂) → 圣遗物秘境×4
  世界Boss×1 (40树脂)
  天赋/武器秘境×2 (40树脂)
  周本Boss×1 (30树脂, 折扣)
  剩余: 10树脂 (灵活使用)

方案B — AR30-44 成长优先:
  天赋秘境×4 (80树脂)
  武器秘境×2 (40树脂)
  世界Boss×2 (80树脂)
  剩余: 0

方案C — 速通 (时间有限的日常):
  浓缩树脂×2 (80树脂, 提前制作)
  世界Boss×1 (40树脂)
  剩余: 80树脂 (浓缩树脂备用)
```

### 2.3 浓缩树脂策略

```
制作条件: 晶核×1 + 40原粹树脂
持有上限: 5个
制作位置: 合成台 (任意城市)

使用场景:
  - 时间不足时：进秘境直接使用浓缩树脂×1 (消耗40树脂, 获得双倍奖励)
  - 圣遗物域：推荐使用浓缩树脂获得双倍5星圣遗物
  - 避免使用: 世界Boss (浓缩不可用)、周本Boss (浓缩不可用)

制作时机:
  - 树脂接近上限(≥160)但暂时不想刷域时
  - 当天秘境日程不匹配需要天赋书时
  - 为第二天提前储备
```

## 三、委托类型识别与处理流程

### 3.1 四种委托类型

| 类型 | 出现比例 | 典型耗时 | 难度 | 识别方式 |
|------|---------|---------|------|---------|
| **战斗委托** (Combat) | ~40% | 2-4分钟 | ★-★★★ | 任务UI文字含"消灭"/"击败"关键词 + 任务标记指向敌群 |
| **收集委托** (Collection) | ~25% | 1-2分钟 | ★ | 任务UI文字含"采集"/"交付"关键词 + NPC交互 |
| **对话委托** (Dialog) | ~20% | 1-3分钟 | ★ | 任务UI文字含"寻找"/"对话"关键词 + 多轮NPC对话 |
| **护送委托** (Escort) | ~15% | 3-5分钟 | ★★-★★★ | 任务UI文字含"护送"/"保护"关键词 + 气球/史莱姆气球目标 |

### 3.2 战斗委托处理流程

```
[战斗委托流程]
  1. 接取委托 (已在任务日志中)
  2. 按 V 激活任务导航 → 小地图显示黄色标记方向
  3. 传送最近锚点 → M → 点击最近传送点 → 确认 → 等待加载
  4. 步行/冲刺到标记点 (使用 quest_marker_follower)
  5. 到达战斗区域 → 检测敌群出现 (YOLO/视觉分类器)
  6. 执行战斗循环:
     - 识别敌人类型和元素属性 (P-28)
     - 选择合适的元素反应策略 (C-07/C-08)
     - 执行技能轮转 (C-01): E → 技能 → 切换 → E → 爆发
     - 处理大型敌人/精英敌人: 优先攻击
  7. 检测"委托完成"弹窗 (P-09) → 等待奖励弹出 → 确认
  8. 重复步骤2-7直到4个委托完成

  [能力映射]
  - P-01: 大世界/战斗状态检测
  - P-03: 小地图任务标记分析
  - P-09: 弹窗/通知检测
  - P-28: 敌人类型识别 (YOLO + VLM)
  - C-01: 技能循环执行 (playbook_executor)
  - C-07/C-08: 元素反应链规划与执行
  - C-12/C-13: 危险检测与反射闪避
  - Q-03: 任务导航线 (V键)
  - Q-07: 委托任务识别 (CommissionManager)
  - I-11: 传送序列 (teleport_sequence)
  - N-03: 任务标记跟随 (quest_marker_follower)
```

### 3.3 收集委托处理流程

```
[收集委托流程]
  1. 按 V 激活任务导航
  2. 传送最近锚点
  3. 导航到目标区域
  4. 在地面搜索可交互物品:
     - 检测 F 键提示闪烁 (P-05)
     - VLM 分析地面物品位置 (P-26)
  5. 按 F 拾取物品
  6. 重复步骤4-5直到进度条满 (通常需要3-8个物品)
  7. 检测"委托完成"弹窗, 确认

  [能力映射]
  - P-05: 交互提示检测 (F键)
  - P-26: VLM 场景理解 (物品识别)
  - P-09: 弹窗/通知检测
  - N-03: 任务标记跟随
  - Q-03: 任务导航线
```

### 3.4 对话委托处理流程

```
[对话委托流程]
  1. 按 V 激活任务导航
  2. 传送到最近锚点
  3. 导航到目标NPC
  4. 按 F 与NPC对话:
     - 检测对话框出现 (P-06)
     - 使用 dialog_driver 自动推进对话 (D-01/D-03)
     - 如遇选项: OCR 读取选项 (P-20) → 选择第一个推进型选项
  5. 对话完成 → 可能触发下一步：
     - 去另一个NPC处 → 重复步骤3-4
     - 拾取物品 → 转入收集模式
     - 战斗 → 转入战斗模式
  6. 检测"委托完成"弹窗, 确认

  [能力映射]
  - P-05: 交互提示检测
  - P-06: 对话框检测
  - P-20: 对话文字 OCR
  - D-01: 对话推进 (dialog_driver)
  - D-02: 对话选项选择
  - D-03: 对话自动播放
  - Q-03: 任务导航线
  - N-03: 任务标记跟随
```

### 3.5 护送委托处理流程

```
[护送委托流程]
  1. 按 V 激活任务导航

  8. 检测"委托完成"弹窗, 确认

  - P-03: 小地图分析
  - P-05: 交互提示检测
```

## 四、速通路线优化

### 4.1 从蒙德城出发的最优传送路线

蒙德城是新手默认根据地，拥有凯瑟琳、合成台、铁匠、烹饪台在步行距离内的高密度布局。

```
[蒙德城中心规划]

  最佳登录点: 蒙德城 (传送锚点: 蒙德城传送点)

  蒙德城行动路线 (Walking Order):
  1. 登录后在凯瑟琳处 (广场)
  2. → 向东: 合成台 (炼金台, 30m)
  3. → 向北: 铁匠铺 (瓦格纳, 50m)
  4. → 向西: 烹饪台 (猎鹿人餐馆, 40m)
  5. → 传送离开

  蒙德城内循环时间: ~2分钟 (不含操作)
```

### 4.2 全国传送路线索引

```
[顶级速通传送路线]
  Step 1: 蒙德城传送点
    → 凯瑟琳领奖
    → 合成台 (浓缩树脂制作/参量质变仪)
    → 铁匠铺 (锻造精锻矿)

  Step 2: 按委托所在区域决定第二传送点
    → 蒙德委托: 前往委托位置 (无需额外传送)
    → 璃月委托: 传送璃月港
    → 稻妻委托: 传送稻妻城
    → 须弥委托: 传送须弥城
    → 枫丹委托: 传送枫丹廷
    → 纳塔委托: 传送圣火体育场

  Step 3: 世界Boss/周本 → 按需传送
    → 利用 world_graph (83KB) 的 Dijkstra 最短路径
    → 优先选择同区域 Boss (减少远程传送)

  Step 4: 秘境/域
    → 使用冒险之证 (F1) → 秘境标签 → 直接传送
    → 替代: M → 点击秘境图标 → 传送
```

### 4.3 区域传送优化建议

```
[区域选择建议]
  - AR 1-25 (蒙德/璃月为主): 默认在蒙德城, 委托在蒙德区域
  - AR 25-35 (解锁稻妻路径): 委托可根据冒险之证地区选择
  - AR 35+ (全区域): 在冒险之证中将委托区锁定在单一区域
    以减少传送时间 (推荐锁定蒙德)

  [锁定委托区域]
  操作路径: F1 (冒险之证) → 委托标签 → 地区选择 (下拉菜单)
    → 选择单一区域 (蒙德/璃月/稻妻/须弥/枫丹/纳塔)
  优势: 4个委托集中在同一区域, 平均传送距离减少50%
```

## 五、第一层：15分钟速通日常 (Quick Daily)

> **目标**：用最短时间完成每日必做，获得基础奖励 (60原石 + AR经验 + 树脂材料)。
> **适用场景**：工作日、快节奏晨间登录、树脂接近上限时的清树脂操作。
> **总耗时**：约12-15分钟 (不含加载时间)。

### 预设条件

```
- 角色已登录, 位于任意主城 (蒙德城/璃月港/稻妻城)
- 当前树脂 >= 40 (可消耗)
- 4个每日委托已刷新
- 邮箱可能有物品
- 参量质变仪: 可能已冷却完成 (每周刷新)
```

### 时间轴

```
T+0:00 ~ T+0:30  阶段 A: 领取每日奖励
──────────────────────────────────────────────
  操作1: 领取每日登录奖励 (如有 HoYoLAB 签到)
    跳过此步 (外部系统, 不影响游戏内操作)

  操作2: 邮箱领取
    UI操作路径: Esc (派蒙菜单) → 邮件图标 → 全部领取 → Esc 返回
    所需能力: P-01 (屏幕状态), U-01 (派蒙菜单), U-02 (邮件界面, 复用菜单导航)
    验收标准: 邮箱内无未领取物品; 原石/摩拉变化可被ResourceManager追踪
    异常处理: 邮件数量>100时"全部领取"可能失败 → 分批领取
    优化提示: 如果邮箱无红点则跳过此步骤; 使用 Y 键快速打开通知

T+0:30 ~ T+1:30  阶段 B: 委托前准备 (检查状态)
──────────────────────────────────────────────
  操作1: 打开任务日志确认委托
    UI操作路径: J (任务菜单) → 委托标签 → 检查4个委托状态
    所需能力: P-01, Q-07 (CommissionManager), P-22 (菜单OCR)
    验收标准: 确认4个委托已分配且类型已知
    异常处理: 如果委托标记异常 → 使用VLM分析当前屏幕

  操作2: 检查树脂状态
    UI操作路径: Esc → 查看右上角树脂数字, 或: M (地图) → 右上角树脂显示
    所需能力: P-21 (数值读取, OCR读取树脂数字)
    验收标准: 确认当前树脂数量
    优化提示: ResourceManager (M-03) 自动追踪树脂, 无需每次OCR

T+1:30 ~ T+10:30 阶段 C: 完成4个每日委托 (约9分钟, 每个约2.5分钟)
──────────────────────────────────────────────
  对于每个委托 i (i=1~4):

  T+0:00 ~ T+0:15  追踪目标委托
    操作: 按 V 激活任务导航线
    UI操作路径: J → 委托标签 → 点击第i个委托 → 追踪
    所需能力: Q-03 (任务导航V键), Q-07 (CommissionManager)
    验收标准: 小地图出现黄色标记方向
    异常处理: 导航线未出现 → 检查是否已追踪; 重新在任务日志中点击追踪

  T+0:15 ~ T+0:45  传送至最近锚点
    操作: M (地图) → 识别最近传送点 (视觉/世界图) → 点击 → 传送到 → 确认
    UI操作路径: M → 定位目标区域 → 点击最近锚点 → 传送确认 → 等待加载
    所需能力: I-11 (传送序列), P-07 (加载画面检测), N-01 (世界图寻路)
    验收标准: 加载完成后角色出现在目标区域; 小地图显示传送锚点已激活
    异常处理:
      - 传送失败 (未激活锚点): 选择次近锚点再传
      - 加载时间>15s: 检测是否卡死 → 按Esc尝试 → 超时重置
    优化提示: 使用 teleport_sequence 的预缓存路径减少地图搜索时间

  T+0:45 ~ T+2:15  步行到委托目标 (约1.5分钟)
    操作: 使用 quest_marker_follower 沿导航线移动
    所需能力:
      - N-03: 任务标记跟随 (quest_marker_follower)
      - N-05: 开放世界步移导航 (genshin_navigator)
      - N-06: 相机伺服 (camera_servo, 维持面向方向)
```

> **目标**：完整日常+周常, 最大化资源获取, 推进深境螺旋进度。


## 附录 A：异常处理与恢复总表

### A.1 通用异常处理

| 异常类型 | 触发条件 | 处理策略 | 最大重试 | 超时时间 |
|---------|---------|---------|---------|---------|
| 加载超时 | loading_screen > 20s | 按 Esc 尝试取消 → 等待再10s → 强制重启 | 2 | 30s |
| 菜单未打开 | 按键后 screen_state 不变 | 等待1s → 重试按键 → 检查焦点 | 3 | 5s |
| UI按钮不可点击 | 点击后无反应 | 等待500ms → 重试点击 → 偏移点击 | 3 | 3s |
| OCR读取失败 | OCR 返回空或低置信 | VLM fallback → 默认坐标点击 | 2 | 2s |
| VLM服务不可用 | API 超时/错误 | 切换到规则化执行 → 使用默认坐标 | — | 10s |
| 窗口焦点丢失 | SafeWindowBackend 检测 | 等待5s → 尝试重新获取焦点 → 通知用户 | 3 | 15s |
| 树脂数据不一致 | OCR读值与ResourceManager不同 | VLM双确认 → ResourceManager覆盖 | — | 1s |
| 委托状态不一致 | OCR vs CommissionExecutor 不同 | 重新扫描任务日志 → 以日志为准 | — | 2s |

### A.2 战斗异常处理

| 异常类型 | 触发条件 | 处理策略 | 后续动作 |
|---------|---------|---------|---------|
| 单角色死亡 | HP条归零 | C-17: 切到存活角色 → 使用复活食物 | 继续战斗 |
| 两队全灭 | 4个角色全部HP=0 | C-18: 复活所有角色 → 重新挑战 | 评估撤退 |
| 输出不足 (timeout) | 战斗>6分钟无进展 | C-33: 放弃判断 → 提升装备后重试 | 标记失败 |
| Boss阶段卡住 | Boss HP 不减 30s+ | 检查无敌机制 → 等待可攻击窗口 | 改变策略 |
| 环境危害致死 | 严寒/雷暴计量条满 | 传送到安全位置 → 治疗 → 重新接近 | 减少停留 |
| 被击飞无法恢复 | 角色倒地 3s+ 不起 | 切换角色 → 冲刺取消硬直 | 继续战斗 |

### A.3 导航异常处理

| 异常类型 | 触发条件 | 处理策略 |
|---------|---------|---------|
| 迷路 (Frustration > 0.7) | ProgressSupervisor检测 | RecoveryPolicy: 回退到最近已知位置 → 重新寻路 |
| 传送后标记丢失 | Q-20 任务标记消失 | 等待2s 刷新 → 重新按V → 或重新在日志中追踪 |
| 锚点未激活 | teleport_sequence 失败 | 选择次近锚点 → 步行较远距离 |
| 地形卡住 | 角色无法移动 5s+ | 冲刺跳越 → 传送最近锚点 → 重试 |
| 水下氧气不足 (枫丹) | E-23 呼吸条 < 20% | 紧急上浮 → 寻找气泡或岸边 |

```
                    ┌─────────────┐
                    │   IDLE      │ (初始/完成状态)

                           ▼
              ┌────────────────────────┐
              │  WEEKLY_BOSS (可选)     │ (周本折扣, 仅周一/周末)
              └───────────┬────────────┘
                          │ weekly_done OR skipped
                          ▼
              ┌────────────────────────┐
              │  EXPEDITIONS            │ (收取+重派)
              └───────────┬────────────┘
                          │ expeditions_done
                          ▼
              ┌────────────────────────┐
              │  FORGING (可选)         │ (锻造+食材)
              └───────────┬────────────┘
                          │ forging_done OR skipped
                          ▼
              ┌────────────────────────┐
              │  REPUTATION (可选)      │ (声望任务, 仅周一)
              └───────────┬────────────┘
                          │ reputation_done OR skipped
                          ▼
              ┌────────────────────────┐
              │  BATTLE_PASS            │ (纪行检查)
              └───────────┬────────────┘
                          │ bp_check_done
                          ▼
              ┌────────────────────────┐
              │  SPIRAL_ABYSS (可选)    │ (深境螺旋, 1-2层)
              └───────────┬────────────┘
                          │ abyss_done OR skipped
                          ▼
              ┌────────────────────────┐
              │  EXTRA_DOMAIN (可选)    │ (额外秘境)
              └───────────┬────────────┘
                          │ extra_done OR skipped
                          ▼
              ┌────────────────────────┐
              │  TEAPOT (可选)          │ (尘歌壶收钱)
              └───────────┬────────────┘
                          │ teapot_done OR skipped
                          ▼
              ┌────────────────────────┐
              │  EVENTS (可选)          │ (限时活动)
              └───────────┬────────────┘
                          │ events_done OR skipped
                          ▼
                    ┌─────────────┐
                    │  COMPLETE   │ (日常完成)
                    └─────────────┘

  阶段转换:
  [COMMISSIONS] 完成后必须进入 [RESIN_SPEND]
  [RESIN_SPEND] 完成后可选进入 [WEEKLY_BOSS] (如折扣未用)
  [WEEKLY_BOSS] 必须接下来进入 [EXPEDITIONS]
  所有后续阶段按顺序执行，跳过条件由调度器判断

  中断处理:
  - 任意阶段检测到 P0 中断 (紧急停止/焦点丢失):
    → 立即进入 EMERGENCY_STOPPED 并 release_all
  - 任意阶段检测到 P1 中断 (看门狗超时):
    → 暂停当前操作, 等待中断解除后恢复
  - 任意阶段检测到 resin_overflow (树脂>=200):
    → 调整优先级, 立即执行 RESIN_SPEND
```
