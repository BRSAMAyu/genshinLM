## UI-01: 角色升级（1-90级）

### 场景描述
将选中的角色从当前等级提升至目标等级。需要消耗经验书（ Wanderer's Advice / Adventurer's Experience / Hero's Wit ）和摩拉。升级受角色突破阶段限制，不可超过当前突破等级对应的等级上限。

### 操作路径
```
开始
  ↓
[打开角色菜单] (按 C 键)
  ↓
[等待角色菜单加载] (检测 world_hud → full_menu)
  ↓
[确认角色详情面板] (右侧显示角色名称、等级、元素)
  ↓
[如需切换角色：点击底部角色条中的目标角色]
  ↓
[点击升级按钮] (确认详情页 → Details tab 已激活)
  ↓
[材料自动填充确认]
  ↓
[等待升级动画] (~500ms)
  ↓
[验证等级变化] (OCR 读取新等级数字)
  ↓
[关闭菜单] (按 Esc)
结束
```

### 子步骤详解

1. **按 C 键打开角色菜单**
   - 操作：发送键盘按键 `C`
   - 等待：检测屏幕状态从 `world_hud` 过渡到 `full_menu` 或 `paimon_menu`
   - 验证：右侧面板显示角色名称 + 等级数字 ROI（参考 1400,120 to 1800,400 at 1920x1080）
   - 超时：3秒内未检测到菜单则重试，最多重试 3 次

2. **等待菜单完全加载**
   - 操作：无操作，仅等待
   - 等待：检测 `full_menu` 状态 + 底部角色条出现
   - 验证：角色条 ROI（0,850 to 1920,920 at 1920x1080）有非空内容
   - 超时：2秒

3. **确认当前查看角色**
   - 操作：检查右侧面板角色名称与目标角色匹配
   - 验证：OCR 读取角色名称 ROI（1500,150 to 1850,220 at 1920x1080）
   - 异常：如不匹配，点击底部角色条对应位置切换角色
     - 角色1位置约 (0.05, 0.88)
     - 角色2位置约 (0.12, 0.88)
     - 角色3位置约 (0.19, 0.88)
     - 角色4位置约 (0.26, 0.88)

4. **点击升级按钮**
   - 操作：点击确认按钮区域 (0.85, 0.85)，归一化坐标
   - 等待：点击动画完成后进入材料确认流程（约 300ms）
   - 验证：弹窗出现或按钮状态变化
   - 超时：1秒

5. **材料自动填充确认**
   - 操作：游戏自动使用背包中的经验书，点击确认区域 (0.65, 0.85)
   - 等待：检测确认弹窗内容变化或"升级成功"通知
   - 验证：通知区域（1400,100 to 1900,500 at 1920x1080）出现升级相关文字
   - 超时：2秒

6. **等待升级动画播放**
   - 操作：无操作，等待动画完成
   - 等待：检测动画结束（屏幕亮度恢复正常，无 loading_screen）
   - 超时：3秒

7. **验证等级变化**
   - 操作：OCR 读取角色等级 ROI（1500,150 to 1700,220 at 1920x1080）
   - 验证：新等级 = 目标等级 或 增量 > 0
   - 异常：等级未变化则重新尝试升级（最多重试 2 次）

8. **关闭菜单**
   - 操作：按 `Esc` 键
   - 等待：检测屏幕状态从 `full_menu` 回到 `world_hud`
   - 验证：小地图（minimap）重新出现
   - 超时：2秒

- 验证条件：等级数字 OCR 增量 = 预期增量
- 资源消耗：摩拉和经验书正确扣减（通过背包 OCR 验证）

## UI-02: 角色突破（20/40/50/60/70/80 → 下一阶段）

### 场景描述
在角色达到当前等级上限时，使用元素晶石、地方特产、普通敌人掉落物和世界 Boss 材料进行突破。每次突破提升等级上限20/40/50/60/70/80。突破有6个阶段。

### 操作路径
```
开始
  ↓
[打开角色菜单] (按 C 键)
  ↓
[选择目标角色]
  ↓
[点击 Details tab] (如果未在详情页)
  ↓
[检测当前等级与等级上限]
  ↓
[点击突破按钮] (当等级达到上限时按钮高亮)
  ↓
[材料自动消耗确认弹窗]
  ↓
[等待突破动画] (金色闪光效果)
  ↓
[验证突破成功] (等级上限+20，元素颜色变化)
  ↓
[关闭菜单]
结束
```

### 子步骤详解

1. **按 C 键打开角色菜单**
   - 操作：发送键盘按键 `C`
   - 等待：检测 `full_menu` 状态
   - 验证：右侧面板显示角色等级和元素图标
   - 超时：3秒，重试 3 次

2. **选择目标角色**
   - 操作：点击底部角色条中目标角色头像
   - 坐标参考（归一化）：角色1-4 分别在 (0.05-0.26, 0.88)
   - 等待：右侧面板切换显示目标角色（300ms）
   - 验证：OCR 确认角色名称

3. **读取当前等级和突破阶段**
   - 操作：OCR 读取等级数字和"突破"标记
   - ROI 参考：等级数字 (1500,150 to 1700,220)；突破材料消耗 (100,400 to 600,800)
   - 验证：当前等级 = 等级上限，确认突破所需材料
   - 异常：如等级未达上限，提示"无需突破"

4. **点击突破按钮**
   - 操作：点击 (0.85, 0.85)（突破/升阶按钮）
   - 等待：点击后出现确认弹窗（约 300ms）
   - 验证：弹窗显示消耗材料列表
   - 超时：2秒

5. **确认材料消耗弹窗**
   - 操作：点击确认区域 (0.65, 0.85)
   - 等待：材料扣除动画 + 突破动画开始
   - 验证：确认弹窗消失，突破动画播放
   - 超时：2秒

6. **等待突破动画**
   - 操作：无操作
   - 等待：检测金色闪光效果或加载状态结束
   - 超时：5秒（含加载）
   - 注意：突破动画有角色模型发光效果，颜色与元素相关

7. **验证突破成功**
   - 操作：OCR 读取新等级上限（应为当前上限 + 20）
   - 额外验证：元素图标变化或新的突破标记出现
   - 异常：等级未变化则重新尝试突破（最多1次重试）

8. **关闭菜单**
   - 操作：按 `Esc` 键
   - 等待：回到 `world_hud` 状态
   - 验证：小地图重新出现
   - 超时：2秒

  - 突破材料消耗正确（参考 `genshin_character_progression.py` 中 AscensionMats 表）
  - 摩拉扣除正确
- 详细日志：记录消耗的每种材料数量

## UI-03: 天赋升级（1-10级，三天赋）

### 场景描述
升级角色的普通攻击（普通攻击）、元素战技（E）、元素爆发（Q）三个天赋。每个天赋从1级升至10级。天赋升级受角色突破阶段限制（6+级需额外皇冠材料）。天赋材料有日期限制（每日/周三/周六/周日可获取不同类型）。

### 操作路径
```
开始
  ↓
[打开角色菜单] (按 C 键)
  ↓
[选择目标角色]
  ↓
[点击 Talents tab] (右侧标签栏)
  ↓
[等待天赋页面加载] (显示三个天赋卡片)
  ↓
[选择要升级的天赋] (普通攻击/E/Q)
  ↓
[点击升级按钮]
  ↓
[确认材料消耗] (材料自动填充)
  ↓
[等待升级动画]
  ↓
[验证天赋等级变化]
  ↓
[重复或关闭菜单]
结束
```

### 子步骤详解

1. **按 C 键打开角色菜单**
   - 操作：发送键盘按键 `C`
   - 等待：检测 `full_menu` 状态
   - 验证：右侧面板显示角色模型
   - 超时：3秒

2. **选择目标角色**
   - 操作：点击底部角色条中目标角色头像
   - 坐标参考：(0.05-0.26, 0.88) 归一化
   - 等待：角色切换完成（300ms）

3. **点击 Talents tab**
   - 操作：点击右侧标签栏中的天赋图标（星形图标）
   - 坐标参考：Tab 栏位于 (0.88, 0.25) 至 (0.95, 0.75)
   - 具体位置：
     - 普通攻击 tab: (0.90, 0.28)
     - 元素战技 tab: (0.90, 0.48)
     - 元素爆发 tab: (0.90, 0.68)
   - 等待：页面切换显示三个天赋卡片（500ms）
   - 验证：三个天赋卡片可见，分别标注"普通攻击""元素战技""元素爆发"

4. **选择目标天赋**
   - 操作：点击要升级的天赋卡片
   - 坐标参考：
     - 普通攻击（左侧）: (0.35, 0.50)
     - 元素战技（中间）: (0.50, 0.50)
     - 元素爆发（右侧）: (0.65, 0.50)
   - 等待：天赋详情展开，显示当前等级和升级按钮（300ms）
   - 验证：天赋名称和等级数字可见

5. **读取当前天赋等级**
   - 操作：OCR 读取天赋等级数字
   - ROI：(0.50, 0.40 to 0.70, 0.50) 归一化区域
   - 验证：确认目标等级 > 当前等级
   - 异常：已达10级返回完成，天赋等级上限受突破限制

6. **点击升级按钮**
   - 操作：点击 (0.85, 0.85)
   - 等待：出现材料确认弹窗（约 300ms）
   - 验证：弹窗显示消耗的天赋书 + 摩拉数量

7. **确认材料消耗**
   - 操作：点击 (0.65, 0.85)
   - 等待：材料扣除动画（500ms）
   - 验证：弹窗关闭，升级动画播放

8. **等待升级动画**
   - 操作：无操作
   - 等待：检测升级成功通知出现
   - 超时：3秒

9. **验证天赋等级变化**
   - 操作：OCR 重新读取天赋等级
   - 验证：新等级 = 旧等级 + 1
   - 异常：等级未变化则重试（最多1次）

10. **决定后续操作**
    - 操作：如还有其他天赋需升级，重复步骤4-9
    - 操作：如已完成，点击 Esc 关闭菜单
    - 验证：`world_hud` 状态
