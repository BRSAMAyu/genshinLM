## 任务场景：序章·第一幕「捕风的异乡人」(AQ-001)

### 任务信息
- 任务ID：AQ001
- 前置任务：无 (新手引导直接触发)
- AR要求：1
- 预计时长：20-30 分钟
- 区域：蒙德

### 任务目标
1. 主目标：完成与安柏的初次相遇，进入蒙德城
2. 次目标：熟悉基本操作（移动、交互、战斗）
3. 可选目标：无

### 子步骤

1. **开场过场动画**
   - 触发：自动播放
   - 验证：过场结束进入大世界
   - 需要的能力：P-31 (CutsceneDetector), I-09 (skip_cutscene)
   - 操作：等待过场结束或按 Esc 跳过

2. **跟随安柏前往蒙德城**
   - 类型：跟随/导航
   - 目标描述：跟随安柏的指引，沿路径前往蒙德城
   - 完成条件：到达蒙德城门口触发剧情
   - 需要的能力：P-03 (小地图分析), P-18 (任务标记), N-01 (路径跟随), D-01 (基础对话)
   - 特殊处理：新手阶段，安柏会在前方等待，不可超前太多

3. **进入蒙德城·与安柏对话**
   - 类型：对话
   - 目标描述：在蒙德城门口与安柏交谈
   - 完成条件：对话框消失，任务追踪更新
   - 需要的能力：P-06 (对话框检测), D-01, I-01 (F键交互)
   - 操作：接近安柏 → F 触发对话 → 连续 F/左键推进 → 如有选项选择默认

4. **与骑士团成员交谈**
   - 类型：对话
   - 目标描述：在骑士团总部内与凯瑟琳/霍夫曼交谈
   - 完成条件：对话结束，任务标记更新指向风神像
   - 需要的能力：P-06, D-01, P-05 (F键提示), N-02 (城内导航)
   - 导航：从城门沿主路 → 右转上楼梯 → 进入骑士团总部

5. **前往风神像广场**
   - 类型：探索
   - 目标描述：到达蒙德城中央广场的风神像处
   - 完成条件：到达指定位置触发过场
   - 需要的能力：P-03, P-18, N-01
   - 导航：从骑士团总部出来 → 左转沿路 → 到达广场中央

6. **与温迪对话·风魔龙出现**
   - 类型：对话 → 过场
   - 目标描述：与温迪交谈后风魔龙袭击蒙德
   - 完成条件：过场结束
   - 需要的能力：P-06, D-01, P-31, I-09
   - 注意：此段有过场动画，不可跳过部分

7. **击退风魔龙（教程战斗）**
   - 类型：战斗（教程）
   - 目标描述：使用安柏击退风魔龙（QTE 教程）
   - 完成条件：战斗结束过场触发
   - 需要的能力：C-01 (基础战斗), I-01, P-02 (战斗指示器)
   - 特殊机制：这是教程战斗，操作被引导，只需按提示按键
   - 失败恢复：教程战斗不可失败

8. **与温迪交谈·任务完成**
   - 类型：对话
   - 目标描述：战斗后与温迪交谈，任务结束
   - 完成条件：获得奖励，任务追踪栏更新为 AQ002
   - 需要的能力：P-06, D-01

### 关键决策点
- 无分支决策（线性任务）

### 能力依赖
| 步骤 | 需要的能力 |
|------|-----------|
| 过场动画 | P-31, I-09 |
| 跟随导航 | P-03, P-18, N-01 |
| 对话(多次) | P-06, D-01, P-05 |
| 教程战斗 | C-01, P-02 |

### 验收标准
- 完成条件：任务追踪显示 AQ001 已完成，AQ002 出现在列表中
- 奖励验证：获得冒险经验、原石、摩拉

### 特殊机制
- 新手引导强制锁定：部分操作在教程中被锁定 | 应对：按提示操作，不自行行动
- 不可跳过的过场 | 应对：等待检测过场结束标志

### 失败恢复
- 本任务无真正失败条件 | 新手教程全程引导
- 如果游戏崩溃/断线 | 恢复策略：重新登录，任务从最近存档点继续

## 任务场景：序章·第二幕「为了没有眼泪的明天」(AQ-002)

### 任务信息
- 任务ID：AQ002
- 前置任务：AQ001
- AR要求：5
- 预计时长：15-25 分钟
- 区域：蒙德

### 任务目标
1. 主目标：与琴团长调查风魔龙事件，恢复风神像
2. 次目标：解锁蒙德周边传送点
3. 可选目标：收集沿途材料

### 子步骤

1. **前往骑士团总部·与琴对话**
   - 类型：导航+对话
   - 触发：追踪 AQ002，V 键导航
   - 验证：对话框出现
   - 需要的能力：P-03, P-18, N-01, D-01, P-06

2. **调查蒙德周边异常**
   - 类型：探索+战斗
   - 目标描述：前往指定地点击败史莱姆/丘丘人
   - 完成条件：所有敌人击败，任务标记更新
   - 需要的能力：C-01, P-02, P-27, N-01
   - 路线：蒙德城 → 低语森林 → 风起地方向

3. **击败遗迹守卫（首次遭遇）**
   - 类型：战斗（Boss 教学）
   - 目标描述：击败首次出现的遗迹守卫
   - 完成条件：遗迹守卫 HP 归零
   - 需要的能力：C-03 (Boss 战), P-10 (Boss 阶段), P-11 (AoE), C-09 (盾牌反制)
   - 特殊机制：遗迹守卫弱点在眼睛（核心），攻击核心可瘫痪
   - 失败恢复：角色死亡 → 七天神像复活 → 重新挑战

4. **返回骑士团汇报**
   - 类型：导航+对话
   - 完成条件：对话结束，获得奖励
   - 需要的能力：N-01, D-01

### 关键决策点
- 无分支决策

### 能力依赖
| 步骤 | 需要的能力 |
|------|-----------|
| 导航+对话 | P-03, P-18, N-01, D-01 |
| 野外战斗 | C-01, P-02, P-27 |
| Boss战 | C-03, P-10, P-11 |

### 验收标准
- 完成条件：任务列表显示 AQ002 完成
- 获得蒙德冒险之证进展

### 特殊机制
- 遗迹守卫首次遭遇教学 | 应对：瞄准核心（眼睛），近身攻击时注意旋转攻击
- 任务强制追踪 | 应对：跟随 V 键导航

### 失败恢复
- 遗迹守卫战斗失败 | 恢复策略：七天神像复活，食物恢复HP，重新挑战
- 角色全灭 | 恢复策略：选择"回到七天神像"，自动传送并复活

## 任务场景：序章·第三幕「巨龙与自由之歌」(AQ-003)

### 任务信息
- 任务ID：AQ003
- 前置任务：AQ002
- AR要求：10
- 预计时长：40-60 分钟
- 区域：蒙德·风龙废墟

### 任务目标
1. 主目标：深入风龙废墟，击败深渊法师，净化特瓦林（风魔龙）
2. 次目标：解开风龙废墟三道屏障
3. 可选目标：收集废墟内宝箱

### 子步骤

1. **前往风龙废墟入口**
   - 类型：导航
   - 目标描述：传送到明冠山地，步行/滑翔到达风龙废墟入口
   - 完成条件：到达废墟入口触发剧情
   - 需要的能力：N-01, P-03, P-18, N-09 (滑翔)

2. **解开第一道风屏障**
   - 类型：解谜
   - 目标描述：找到并激活附近的风元素方碑
   - 完成条件：风屏障消失
   - 需要的能力：P-29 (谜题状态), I-01 (攻击方碑), P-15 (体力管理)
   - 特殊机制：需要使用风元素攻击方碑；安柏可用弓箭远程激活

3. **深入废墟·击败深渊教团敌人**
   - 类型：战斗
   - 目标描述：在废墟内部击败深渊法师和深渊使徒
   - 完成条件：所有敌人击败
   - 需要的能力：C-01, C-09, P-12 (元素附着), P-28
   - 注意：深渊法师有元素盾，需要使用克制元素打破

4. **解开第二道、第三道屏障**
   - 类型：解谜+导航
   - 目标描述：继续深入，解开剩余屏障
   - 完成条件：所有屏障解开，到达特瓦林所在层
   - 需要的能力：P-29, N-07 (攀爬), N-09 (滑翔), P-15
   - 特殊机制：部分区域需要攀爬高墙 + 滑翔跨越间隙

5. **风魔龙Boss战（第一阶段）**
   - 类型：Boss 战（特殊机制）
   - 目标描述：在风魔龙背上战斗，击败寄生虫
   - 完成条件：第一阶段寄生虫清除
   - 需要的能力：C-03, C-06 (弓箭瞄准), P-02, C-48 (DvalinPlatformTracker)
   - 特殊机制：
     - 风魔龙会倾斜平台，需要调整站位避免掉落
     - 使用安柏的弓箭射击背上的寄生虫
     - 平台倾斜时需要反方向移动
   - 失败恢复：掉落/死亡 → 重试该阶段

6. **风魔龙Boss战（第二阶段：气流射击）**
   - 类型：Boss 战（射击）
   - 目标描述：在气流中飞行，射击风魔龙身上的脓疱
   - 完成条件：所有脓疱击破
   - 需要的能力：C-06 (弓箭瞄准), N-09 (滑翔), P-15 (体力管理)
   - 特殊机制：
     - 按空格键进入上升气流
     - 使用安柏的蓄力弓箭射击远距离目标
     - 需要在体力耗尽前回到平台

7. **风魔龙Boss战（第三阶段：最终净化）**
   - 类型：Boss 战（近战）
   - 目标描述：在风魔龙头部战斗，净化深渊污染
   - 完成条件：Boss HP 归零，过场动画触发
   - 需要的能力：C-01, C-03, P-10, P-11
   - 特殊机制：Boss 低血量进入狂暴，攻击频率增加

8. **与众人对话·任务完成**
   - 类型：对话+过场
   - 完成条件：获得奖励，蒙德危机解除
   - 需要的能力：D-01, P-31

### 关键决策点
- 无分支决策（线性任务）

### 能力依赖
| 步骤 | 需要的能力 |
|------|-----------|
| 导航到废墟 | N-01, N-09, P-18 |
| 风屏障解谜 | P-29, I-01, P-15 |
| 深渊法师战斗 | C-01, C-09, P-12 |
| Boss战P1 | C-03, C-06, C-48, P-02 |
| Boss战P2 | C-06, N-09, P-15 |
| Boss战P3 | C-01, C-03, P-10 |

### 验收标准
- 完成条件：过场动画播放完毕，任务列表显示 AQ003 完成
- 特瓦林不再出现在大世界中
- 获得四风守护成就

### 特殊机制
- 风龙废墟多层立体结构 | 应对：P-15 体力管理 + N-07 攀爬 + N-09 滑翔
- Boss 战平台倾斜机制 | 应对：C-48 DvalinPlatformTracker 追踪倾斜角度
- 上升气流射击机制 | 应对：C-06 弓箭蓄力 + 空格键时机把握

### 失败恢复
- Boss 战失败 | 恢复策略：从最近检查点重试，检查食物/角色等级
- 攀爬体力不足坠落 | 恢复策略：降落到安全平台，恢复体力后重试
- 滑翔时体力耗尽 | 恢复策略：降落到最近平台，避免高空直接坠落

## 任务场景：第一章·第一幕「浮世浮生千岩间」(AQ-004)

### 任务信息
- 任务ID：AQ004
- 前置任务：序章全部完成
- AR要求：23
- 预计时长：60-90 分钟
- 区域：璃月

### 任务目标
1. 主目标：参加璃月「请仙典仪」，目睹岩神遇害，逃避追捕
2. 次目标：结识璃月主要角色（刻晴、凝光、魈等）
3. 可选目标：解锁璃月传送点

### 子步骤

1. **前往璃月港**
   - 类型：跨区域导航
   - 目标描述：从蒙德出发，经过石门/达达乌帕谷路线到达璃月
   - 完成条件：到达璃月港触发过场
   - 需要的能力：N-01, P-03, P-18, N-02 (跨区域路径规划)
   - 路线选项：
     - 路线A（安全）：蒙德城 → 石门 → 轻策庄 → 望舒客栈 → 璃月港
     - 路线B（传送）：已解锁璃月传送点则直接传送

2. **参加请仙典仪**
   - 类型：过场动画
   - 目标描述：到达玉京台，观看请仙典仪
   - 完成条件：过场动画结束，岩神「遇害」
   - 需要的能力：P-31, I-09
   - 注意：重要剧情过场，不可跳过

3. **逃离千岩军追捕**
   - 类型：逃跑/潜行
   - 目标描述：从玉京台逃离，躲避千岩军巡逻
   - 完成条件：到达安全区域
   - 需要的能力：N-01, Q-10 (潜行), Q-21 (守卫视野), P-03
   - 特殊机制：不可与千岩军战斗（剧情强制逃跑），被发现则扣血并重置位置
   - 路线：从玉京台 → 后巷 → 跳下城墙 → 到达码头区域

4. **与仙人对话·获得帮助**
   - 类型：对话
   - 目标描述：在安全区域与帮助者（通常为魈或萍姥姥）对话
   - 完成条件：对话结束，获得下一步指示
   - 需要的能力：D-01, P-06

5. **调查请仙典仪真相**
   - 类型：调查
   - 目标描述：收集线索，走访多个NPC
   - 完成条件：所有线索收集完毕
   - 需要的能力：D-01, P-06, Q-12 (调查机制), P-27 (NPC识别)

### 关键决策点
- 逃跑路线选择 | 影响：选择隐蔽路线更安全但更慢，直线路线快但容易被发现

### 能力依赖
| 步骤 | 需要的能力 |
|------|-----------|
| 跨区域导航 | N-01, N-02, P-18 |
| 请仙典仪 | P-31 |
| 逃离追捕 | Q-10, Q-21, N-01 |
| 调查 | Q-12, D-01, P-27 |

### 验收标准
- 完成条件：任务追踪显示 AQ004 完成，AQ005 出现
- 获得璃月区域的初步探索进度

### 特殊机制
- 逃跑不可战斗 | 应对：纯导航行为，避免接触千岩军
- 请仙典仪强制过场 | 应对：等待结束

### 失败恢复
- 逃跑被发现 | 恢复策略：任务不会真正失败，扣血后自动回到上一个检查点
- 角色死亡 | 恢复策略：七天神像复活

## 任务场景：第一章·第二幕「璃月港的繁星」(AQ-005)

### 任务信息
- 任务ID：AQ005
- 前置任务：第一章第一幕（AQ-004）完成
- AR要求：25
- 预计时长：60-90 分钟
- 区域：璃月·绝云间/遁玉陵

### 任务目标
1. 主目标：与凝光对话了解岩神契约，探索绝云间寻找仙众
2. 次目标：调查石门附近的异常，前往遁玉陵调查
3. 可选目标：解锁璃月更多传送点

### 子步骤

1. **与凝光对话·了解岩神契约**
   - 类型：对话
   - 目标描述：在璃月港与凝光对话，了解岩神死后的璃月局势
   - 完成条件：对话结束，获得新任务指引
   - 需要的能力：D-01 (对话推进), P-06 (对话框检测), P-05 (F键提示)
   - 导航：璃月港 → 玉京台 → 找到凝光（蓝发角色，愚人众围城期间在码头附近）

2. **前往绝云间·寻找仙众**
   - 类型：跨区域导航
   - 目标描述：从璃月港出发，前往绝云间区域
   - 完成条件：到达绝云间，触发与留云借风真君的对话
   - 需要的能力：N-01 (大世界导航), P-03 (小地图分析), P-18 (任务标记)
   - 路线：璃月港 → 传送至绝云间 → 步行至留云借风真君所在处

3. **与削月筑阳真君对话**
   - 类型：对话
   - 目标描述：在绝云间与削月筑阳真君交谈，获取关于岩神契约的信息
   - 完成条件：对话结束，任务标记更新
   - 需要的能力：D-01, P-06, P-05
   - 特殊机制：仙众会提供能力增益（如攻击力提升），善用此增益

4. **调查石门附近的异常**
   - 类型：调查

2. 次目标：前往冒险者协会（凯瑟琳）领取额外奖励
3. 可选目标：达成委托内的隐藏条件

### 通用流程

1. **检查每日委托列表**
   - 操作：F1 键打开冒险之证 → 委托标签
   - 验证：显示4个委托名称、位置、类型
   - 需要的能力：U-08 (冒险之证), P-22 (OCR读取)

2. **逐一完成4个委托**
   - 每个委托的类型和应对策略：

   **2a. 战斗类委托（最常见）**
   - 类型：战斗
   - 描述：击败指定区域的敌人（丘丘人、史莱姆、盗宝团等）
   - 完成条件：全部敌人击败
   - 需要的能力：C-01, P-02, P-28, N-01
   - 典型流程：
     - V 键追踪委托 → 传送到最近传送点 → 步行到标记位置
     - 击败所有敌人 → 委托完成通知弹出
   - 时间：2-4 分钟
   - 常见示例：
     - 「丘丘人的金色摇滚」：击败丘丘人暴徒，地点多在低语森林或星落湖附近
     - 「警惕美术学院」：击败盗宝团成员，地点通常在璃月港周边
     - 「永不小队」：击败丘丘萨满和丘丘人组合，地点随机
     - 「大发生」：击败大量史莱姆，地点多在水边

   **2b. 收集类委托**
   - 类型：探索+收集
   - 描述：采集指定物品（蘑菇、矿石、花等）
   - 完成条件：收集足够数量
   - 需要的能力：P-27, E-02, N-01
   - 典型流程：
     - 追踪委托 → 导航到标记区域 → 使用元素视野寻找目标 → 采集
   - 时间：2-3 分钟
   - 常见示例：
     - 「失踪的画家」：采集画家需要的花朵或植物，地点在须弥雨林或蒙德草原
     - 「旧爱新欢」：收集散落的物品或信件，地点多为建筑物附近
     - 「高效麻绳」：采集足够的麻绳原料，地点多在稻妻
     - 「安全距离」：采集特定位置的物品，注意避开周围敌人

   **2c. 护送类委托**
   - 类型：护送
   - 描述：保护NPC或物品从A点到B点
   - 完成条件：安全到达目的地
   - 需要的能力：Q-11 (护送), C-01, P-02
   - 典型流程：
     - 找到护送目标NPC → 跟随NPC前进 → 途中击败敌人 → 到达终点
   - 时间：3-5 分钟
   - 常见示例：
     - 「护送任务」：护送商人/旅行者安全到达目的地，途中击败盗贼
     - 「货物送达」：护送货物车辆，击败途中袭击的敌人
     - 「紧急护送」：快速护送NPC，限时完成
   - 特殊机制：
     - NPC会自动沿路线移动
     - 途中会有敌人出现
     - NPC 血量为0则失败
   - 失败恢复：从起点重新开始

   **2d. 对话类委托**
   - 类型：对话
   - 描述：与指定NPC交谈
   - 完成条件：对话结束
   - 需要的能力：D-01, P-06, N-01
   - 时间：1-2 分钟
   - 常见示例：
     - 「冒险家提洛尔」：与冒险家提洛尔对话，地点多在蒙德城或望风山地
     - 「酒蒙子」：与璃月的爱酒之人对话，地点多在璃月港的酒馆或码头
     - 「诗人外向」：与诗人NPC对话，地点随机
     - 「寻猫启事」：与委托寻猫的NPC对话，实际上是恶作剧

   **2e. 解谜类委托**
   - 类型：解谜
   - 描述：完成小型谜题（元素方碑、火把等）
   - 完成条件：谜题解决
   - 需要的能力：P-29, I-01
   - 时间：2-3 分钟
   - 常见示例：
     - 「元素专家」：使用指定元素激活方碑
     - 「火炬大师」：点燃所有火把

3. **前往凯瑟琳领取额外奖励**
   - 类型：导航+对话
   - 操作：传送到蒙德/璃月/稻妻/须弥/枫丹/纳塔的冒险者协会 → 与凯瑟琳对话 → 选择「领取委托奖励」
   - 验证：获得额外奖励（冒险经验、摩拉、好感经验）
   - 需要的能力：N-01, D-01, P-06

### 关键决策点
- 委托完成顺序 | 影响：无，可按任意顺序完成
- 区域选择 | 影响：不同区域有不同委托池

- 委托内战斗失败 | 恢复策略：复活后原地重试
- 护送NPC死亡 | 恢复策略：从起点重新开始

     - 开始挑战，抵御敌人波次
     - 根据表现获得评分（完美/优秀/良好/及格）
   - 特殊机制：
     - 不同机关有不同功能（范围伤害、减速、控制）
     - 需要根据敌人类型选择合适的机关
     - 机关可以升级强化
     - 每关有3波敌人，难度递增
   - 奖励：根据评分获得活动货币

8. **机关棋谭全关卡通关**
   - 类型：重复挑战
   - 目标描述：通关所有机关棋谭关卡
   - 完成条件：获得全关卡通关奖励
   - 需要的能力：P-26, I-02, S-10 (策略学习)
   - 关卡数量：通常6-8关
   - 时间：30-60分钟

#### Phase 4：焰羽星花（烟花制作）

9. **接受烟花委托**
   - 类型：对话
   - 目标描述：与烟花的制作者对话接取任务
   - 完成条件：了解烟花制作需求
   - 需要的能力：D-01, P-06

10. **收集烟花材料**
    - 类型：收集
    - 目标描述：收集制作烟花所需的材料
    - 完成条件：收集足够数量的材料
    - 需要的能力：E-02, P-27, N-01
    - 材料类型：
      - 「焰草」：在璃月周边采集
      - 「星尘」：击败敌人概率掉落
      - 「导能之火核心」：活动特殊掉落
    - 特殊机制：
      - 部分材料需要通过战斗获取
      - 部分材料有每日获取上限
      - 使用活动加成角色可以提高掉落率

11. **制作烟花**
    - 类型：制作小游戏
    - 目标描述：按照配方制作烟花
    - 完成条件：成功制作指定数量的烟花
    - 需要的能力：P-22 (OCR读取配方), P-29, I-01
    - 特殊机制：
      - 不同配方需要不同材料组合
      - 材料比例影响烟花质量
      - 高质量烟花可获得额外奖励

#### Phase 5：其他活动内容

12. **参与海灯节小游戏（随机）**
    - 类型：特殊玩法
    - 目标描述：参与节日期间的小游戏
    - 完成条件：根据小游戏类型完成目标
    - 需要的能力：P-29, I-01, I-02
    - 小游戏类型（每年不同）：
      - 「百发百中」：射靶小游戏
      - 「轻飘飘的难题」：飞行挑战
      - 「急就章」：快速烹饪挑战

13. **领取每日签到奖励**
    - 类型：简单操作
    - 目标描述：每日签到领取奖励
    - 完成条件：签到成功
    - 需要的能力：U-10

#### Phase 6：兑换奖励

14. **前往活动商店**
    - 类型：商店兑换
    - 目标描述：使用活动货币兑换奖励
    - 完成条件：兑换想要的物品
    - 需要的能力：U-10, U-35 (商店购买), P-22
    - 可兑换物品：
      - 原石（限定）
      - 天赋培养材料
      - 摩拉/经验书
      - 限定家具图纸
    - 特殊机制：
      - 部分物品有购买上限
      - 优先兑换限定物品（如原石、角色培养材料）
      - 合理规划货币使用

15. **领取成就奖励**
    - 类型：成就系统
    - 目标描述：达成活动成就获得额外奖励
    - 完成条件：完成所有可达成成就
    - 需要的能力：P-22

### 关键决策点
- 活动货币分配 | 影响：优先兑换高价值物品
- 每日体力分配 | 影响：平衡活动任务和日常任务
- 机关棋谭难度选择 | 影响：困难模式奖励更高但难度更大

### 能力依赖
| 步骤 | 需要的能力 |
|------|-----------|
| 活动接取 | U-10, P-22 |
| 剧情对话 | D-01, P-06, N-01 |
| 机关棋谭 | P-26, I-02, S-10 |
| 材料收集 | E-02, P-27, C-01 |
| 烟花制作 | P-22, P-29 |
| 商店兑换 | U-10, U-35, P-22 |

### 验收标准
- 完成条件：全部剧情完成 + 机关棋谭通关 + 商店兑换完毕
- 获得全部活动奖励（原石、天赋材料、限定物品）

### 特殊机制
- 逐日开放 | 应对：每日登录检查新开放内容
- 活动货币 | 应对：优先完成高回报任务
- 体力限制 | 应对：合理规划每日体力使用
- 小游戏规则 | 应对：P-26 VLM理解 + 攻略搜索

### 失败恢复
- 机关棋谭失败 | 恢复策略：重新挑战或调整机关布局
- 材料不足 | 恢复策略：次日刷新或使用原石购买（不推荐）
- 活动结束 | 恢复策略：无法恢复，下次海灯节再见

## 任务步骤状态转换图

```
[接受任务] → [导航到目标] → [执行步骤] → [验证完成]
                                              ↓
                                          [完成?] ─否→ [失败恢复] → [重试]
                                              ↓是
                                        [下一步骤]
                                              ↓
                                      [全部完成?] ─否→ [回到导航]
                                              ↓是
                                        [任务完成]
                                              ↓
                                        [领取奖励]
```

每个步骤的状态：
- NOT_STARTED: 任务/步骤尚未开始
- IN_PROGRESS: 正在执行中
- COMPLETED: 已完成
- FAILED: 执行失败（可重试）
- BLOCKED: 前置条件未满足
