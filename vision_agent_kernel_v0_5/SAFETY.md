# Safety

This project is for self-built testbeds, authorized data and local QA sandboxes only.

## Prohibited

- Online game automation.
- Memory reading or process injection.
- Anti-cheat bypass.
- Driver-level or hardware-level input injection.
- Raw LLM-issued key or mouse commands.
- Controlling windows outside the explicit pseudo3d testbed or authorized target.

## Defaults

- Default mode is `dry-run`.
- `ConsoleInputBackend` prints actions and never touches OS input.
- `safe-window` must be explicitly selected and checks target focus before input.
- Skill recording defaults to record and inspect. Replay defaults to dry-run.
- Test-window recording is restricted to focused authorized pseudo3d/testbed/QA windows. The global hook recorder is only an interface stub and is disabled by default.
- Safe-window Skill replay requires explicit confirmation and target focus before actions become `InputLease` commands.
- Combat reflex modules emit interrupts and dry-run dodge intents unless safe-window execution is explicitly enabled.
- Product E2E safe-window mode rejects execution unless the selected window title matches authorized testbed markers and user confirmation is present.

## Emergency Stop

- F9 triggers emergency stop in integration runners.
- Ctrl+C / SIGTERM requests shutdown.
- `InputWorker.stop()` and failure paths call `release_all`.

## Lease Discipline

All physical input must go through `InputLease` and `InputWorker`. Controller and Orchestrator do not directly call OS input APIs.

## Planner Discipline

LLM providers can only call safe service tools such as `list_skills`, `create_task_spec`, `select_skill_chain`, `pause_agent`, and `emergency_stop`. Forbidden tools include `raw_key_input`, `raw_mouse_input`, `direct_click`, `direct_press_key`, and `bypass_safety`.

Real LLM providers read API keys only from environment variables. Provider errors, rate limits, timeout failures and budget guard failures must fall back to mock planning instead of crashing the Agent. Every TaskSpec generated by an LLM must pass sandbox validation and still requires user confirmation before execution.
